# Sancea Digital Showroom

Design ONLY. Do not build functionality, backend, database, API, authentication, payment system, CMS, or booking system.

Create a modern, elegant, premium website design concept for:

SANCEA KEBAYA & MAKEUP
Kebaya Rental • Makeup • Bridal • Graduation • Wedding
Based in Bali / Denpasar

The website should transform Sancea's current link-in-bio experience into a more professional DIGITAL CATALOG / ONLINE SHOWROOM.

IMPORTANT:
Sancea already has many services and a large collection of kebaya. The main goal of this website design is to make it easier for customers to:
- Explore kebaya collections
- See different categories and styles
- Understand rental packages and pricing
- See makeup and bridal services
- View portfolio
- Find location
- Contact the appropriate WhatsApp admin

The design should feel like a premium fashion boutique / bridal studio, NOT a generic rental website.

BRANDING DIRECTION:
Use the existing Sancea visual identity as inspiration:
- Elegant
- Feminine
- Traditional Balinese / Indonesian fashion influence
- Premium and luxurious
- Black / deep charcoal as a strong base
- Champagne gold / warm gold as accent
- Ivory / warm cream for balance
- Subtle sophisticated typography
- Avoid bright blue, neon colours, or playful startup aesthetics
- Avoid excessive gradients

DESIGN STRUCTURE:

1. HERO SECTION
Create a strong fashion-editorial hero section.

Use a large high-quality kebaya photography area.

Brand:
"SANCEA"
"Kebaya & Makeup"

Headline:
"Elegance for Every Special Moment"

Supporting text:
"Premium Kebaya Rental, Makeup & Bridal Services in Bali"

Primary CTA:
"Explore Collection"

Secondary CTA:
"Consult via WhatsApp"

Make this section visually luxurious, spacious, and photography-focused.

2. INTRODUCTION
Introduce Sancea briefly as a destination for kebaya rental and beauty services.

Highlight:
- 500+ Kebaya Collections
- Sizes XS–5XL
- Kebaya Rental
- Makeup
- Bridal Services

Use elegant statistic / feature cards.

3. KEBAYA COLLECTION
This should be the MAIN section of the website.

Create a beautiful fashion catalog layout with large photography.

Categories:
- Wisuda
- Wedding
- Bridesmaid
- Traditional / Adat
- Engagement
- Event
- Other Collections

Create visually rich category cards.

Each collection card should contain:
- Large kebaya image
- Collection name
- Short description
- "View Collection" button

The layout should feel like a premium fashion catalog.

4. FEATURED COLLECTION
Create a sophisticated editorial gallery showing several kebaya looks.

Use a mixture of portrait and landscape image cards.

Focus heavily on photography and elegant spacing.

5. SERVICES
Create premium service cards for:
- Kebaya Rental
- Makeup
- Bridal
- Wedding
- Graduation
- Bridal Shoes & Accessories

Each service should have an image, title, short description, and subtle CTA.

6. PRICING / PACKAGE
Create a clean premium pricing section.

Do NOT make it look like a SaaS pricing table.

Use elegant cards for:
- Kebaya Rental
- Graduation Package
- Makeup
- Bridal Package

Include:
"Starting From"
and a CTA:
"Ask for Price"

Keep the design flexible because actual prices can be added later.

7. WHY SANCEA
Create 4 elegant highlights:
- 500+ Collections
- XS–5XL Available
- Complete Bridal Services
- Professional Service

Use minimal icons and premium typography.

8. PORTFOLIO
Create an editorial image gallery featuring:
- Kebaya clients
- Graduation
- Wedding
- Makeup
- Bridal styling

The portfolio should visually communicate quality and trust.

9. TESTIMONIALS
Create elegant customer testimonial cards.

Include:
- Client photo placeholder
- Client name
- Service used
- Short testimonial

Keep it clean and trustworthy.

10. LOCATION
Create a clean location section.

Show:
"Sancea Kebaya & Makeup"
"Denpasar, Bali"

Include a visual map placeholder and:
"View Location"

11. WHATSAPP / BOOKING CTA
Create a strong final CTA section:

"Find Your Perfect Look"

Supporting text:
"Explore our collection and consult with our team for your special occasion."

Button:
"Consult via WhatsApp"

12. FOOTER
Minimal luxury footer containing:
- Sancea logo/name
- Kebaya & Makeup
- Instagram
- WhatsApp
- Location
- Quick links

VISUAL STYLE:
- Premium fashion boutique
- High-end bridal editorial
- Indonesian traditional fashion meets modern luxury
- Strong photography
- Generous whitespace
- Elegant serif headline font
- Clean modern sans-serif body font
- Thin gold decorative lines
- Subtle borders
- Minimal shadows
- Refined rounded corners
- Sophisticated black, ivory and champagne-gold palette
- Mobile-first responsive layout

IMPORTANT:
The website must NOT feel like a generic template.

It should feel like a real premium fashion / bridal brand website designed specifically for Sancea Kebaya & Makeup.

Focus ONLY on:
UI design
UX layout
Typography
Spacing
Color palette
Photography placement
Cards
Buttons
Navigation
Responsive visual composition

Do not implement functionality or backend.
