# Frontend routes

TanStack Router handles navigation inside the React application.
Laravel serves the Blade shell for direct requests using routes/web.php.

- index.tsx: /
- katalog.tsx: /katalog
- produk.$slug.tsx: /produk/{slug}
- __root.tsx: shared providers, metadata, and error boundary

When adding a page, register its URL in Laravel as well.
resources/js/routeTree.gen.ts is generated by the Vite router plugin.
