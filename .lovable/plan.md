# Sancea Digital Showroom Design

## Direction
Create a polished, responsive one-page digital catalog for Sancea Kebaya & Makeup. The experience will feel like a high-end bridal editorial: deep charcoal foundations, warm ivory breathing room, champagne-gold details, elegant serif headlines, and restrained modern body type.

## Page composition
- Build a refined navigation and photography-led opening section with the supplied brand message and two visual calls to action.
- Introduce Sancea with boutique-scale statistics and service highlights.
- Make the kebaya catalog the visual centerpiece, with seven large category stories and varied editorial image proportions.
- Add a mixed-format featured collection gallery and premium service cards.
- Present four flexible “Starting From” package cards without a generic software-pricing appearance.
- Add trust highlights, portfolio gallery, testimonials, Denpasar location presentation, final WhatsApp callout, and minimal luxury footer.

## Visual system
- Define all colors, typography, borders, spacing, and restrained motion as reusable design tokens.
- Use an ivory, charcoal, and champagne-gold palette with thin rules, minimal shadows, and subtly refined corners.
- Pair a sophisticated editorial serif with a clean sans-serif; load fonts correctly in the page head.
- Use cohesive generated fashion photography representing Balinese/Indonesian kebaya, bridal, graduation, makeup, and accessories.
- Preserve generous whitespace and asymmetrical editorial rhythm while keeping the mobile experience highly scannable.

## Interaction scope
- Buttons and links will be visual design elements only; no booking, forms, messaging integration, maps integration, authentication, payments, CMS, database, or backend behavior will be added.
- Category, service, and gallery treatments will include refined visual states without implementing data-driven functionality.

## Responsive and quality checks
- Adapt the composition for mobile, tablet, and desktop with stable image proportions and readable type.
- Verify the finished page visually at desktop and mobile sizes, including image loading, spacing, and overlap checks.
- Add page-specific title and social metadata for the Sancea concept.
